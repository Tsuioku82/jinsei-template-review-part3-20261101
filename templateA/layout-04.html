MEMORY TICKET私の歩んだ人生

出発地：ふるさと

寄り道も、私の道でした。

出発

MEMORY TICKET川のある町から

出発地は、川と田畑に囲まれた町。遠くへ出かけても、ふるさとの水音と土の匂いは道しるべでした。

発見

MEMORY TICKET何度も、つくってみる

最初の寄り道は、ものづくり。紙飛行機を折り直し、小さな棚を作りながら、自分なりの道を探しました。

出会い

MEMORY TICKET恩師が教えてくれた歩き方

学校で出会った先生は、「自分の手で確かめて」と背中を押してくれました。長く携えてきた旅の助言です。

MEMORY TICKET仕事という、長い旅

家具づくりの仕事は、急がず、確かに進む旅でした。木を読み、見えない場所まで丁寧に仕上げてきました。

MEMORY TICKET隣を歩いてくれた人

家族と歩いた道には、夕食の話や休日の笑い声が残ります。何でもない日を、ともに過ごした同行者たちです。

乗り換え

MEMORY TICKET庭へ向かう、小さな分岐点

一区切りのあと、小さな庭へ乗り換えました。足元の季節に気づく、新しい暮らしの始まりでした。

  1. 1946昭和21年・0歳
    ふるさとで生まれる

    身近な風景に囲まれて育つ。

  2. 1964昭和39年・18歳
    学びから、新しい暮らしへ

    人との出会いから、少しずつ世界が広がる。

    その年の世の中：東京オリンピック開催 日本オリンピック委員会

  3. 1970昭和45年・24歳
    仕事と日々を重ねる

    目の前のことに向き合いながら歩む。

    その年の世の中：大阪で日本万国博覧会開催 外務省

  4. 2019平成31年／令和元年・73歳
    好きなことを大切に

    暮らしの中に、新しい楽しみを見つける。

    その年の世の中：元号が平成から令和へ 内閣府

  5. 2026令和8年・80歳
    いま、そしてこれから

    感謝と小さな希望を胸に、時を重ねる。

MEMORY TICKET趣味・思い出・喜びと苦難

忘れられない旅は、遠さでは決まらない。

思い出の行き先

MEMORY TICKET列車で、海の町へ

海の見える町へ、列車で出かけました。駅弁の味と夕方の波、道中の会話が、ひと続きの思い出です。

MEMORY TICKET家のそばにも、発見がある

いつもの道具、いつもの庭にも発見があります。旅の楽しみは、遠くに行くことだけではないと感じます。

MEMORY TICKET椅子を届けた、嬉しい帰り道

家族に直した椅子を渡した時の笑顔。誰かの暮らしに役立った、嬉しい寄り道でした。

雨宿りの時間も、旅の一部。

思うように進めない日は、周りの人に支えられました。雨宿りをした時間も、ここまでの道に含まれます。

MEMORY TICKET今の私と未来へのメッセージ

次の行き先は、自分の歩幅で。

現在地

MEMORY TICKET今日という町で暮らす

今の現在地は、窓から庭を眺められる毎日。散歩や読書、道具の手入れを自分の歩幅で楽しみます。

次の目的地

MEMORY TICKETまだ知らない町へ

次に降りたいのは、まだ知らない町の駅。大切な人と、もう一つ思い出を持ち帰りたいと思います。

MEMORY TICKET同行してくれた、みなさんへ

長い道をご一緒してくれた家族、仲間、友人へ。立ち寄ってくれた時間に、心から感謝しています。

MEMORY TICKET速さより、あなたらしい道を

速く進む人と比べなくていい。目の前の一歩を丁寧に、あなたに合った道を歩いてください。

大切なあなたへ

一緒に笑い、支え合ってきた時間に、ありがとう。これからを歩く皆さんが、自分らしい道を見つけられますように。

春夫より
