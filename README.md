# 人生の履歴書｜三篇でつづる私の物語（パート3）

これは3回目の改修版です。パート1・2は別リポジトリ・別URLで保存しており、上書きしていません。

人物と経歴は架空の見本です。男性用10案・女性用10案を、それぞれ専用の10配色で比較できます。画面は1ページ内の3章構成です。

1. index.htmlで男性用・女性用を選びます。配色は各種類専用です。
2. 見本を開き「デザイン・配色・文字の大きさを選ぶ」で変更します。
3. 標準18px、拡大20px・22px。女性用02・05・09に各案専用の人型魔女と「なし」があります。別のキャラクターは対応するデザインで選べます。
4. 「動きを止める」でスクロール演出とGIFを停止できます。端末側の動きを減らす設定も尊重します。お預かりした写真は押して拡大します。
5. 選択はこのブラウザーとURLに残ります。印刷ボタンもあります。

一覧の「情報と写真の記入シート」には質問・記述事項・架空の記述例・写真一覧・公開前の確認があります。A4・16ページのPDFをダウンロードできます。記入内容を送信するWebフォームではありません。

制作者向け：20案の本文はeditions/A01.cjs〜B10.cjsで個別に実装。表紙はeditions/covers.cjs、見出しはornamented-type.cjs、大きな飾り文字はdisplay-lettering.cjs、写真説明・年表・署名はsecondary-lettering.cjs、章・小節の色はsection-colors.cjs、章の境界はtransitions.cjs、各案のスクロール演出はchoreography.cjsです。配色・選択操作・3章ナビは読みやすさのための共通機能です。

専用生成素材20点、専用フレーム8点、装飾GIF5点を収録しています。これらは装飾であり、掲載するお客様の写真ではありません。明るい面の本文はブラウン寄りの柔らかい黒、暗い面では柔らかい白を基本に、各章・小節の囲い内の面色と組み合わせています。

文章はtemplateA又はtemplateB/content/sample.jsonで管理します。chaptersが共通原稿。editorialEditionsには、同じ架空人物の事実を各案の文体へ編集した見本文章があります。chaptersを変更すると照合が外れ、共通原稿へ戻ります。実在のお客様の制作は、この架空の見本帳と分け、専用の制作場所と掲載確認を用意してください。

写真はcustomerPhotosにsource: "customer"、src、alt、captionを指定します。未提供の場合は写真の空欄を表示します。生成した人物や風景を本人の写真として代用しません。提供者・掲載範囲・人物の掲載確認は、記入シートで確認してください。

情報記入シートの原稿はinformation-data.cjsです。家族、苦労した体験、声などは書きたい範囲だけで構いません。

生成：node build.cjs。確認：node check.cjs。表示：node preview.cjs。Node.jsの標準機能で実行できます。生成済みのHTML・CSS・JSを含むため、GitHub Pagesではそのまま表示できます。

見本一覧の画像はassets/edition-previewsにある実際の画面200点です。表紙や配色を変えた場合は撮り直します。簡略図で代用しません。原本・個人管理ログ・確認用の_checksは公開対象から外してください。

今回は静的なリンク・構造・配色、デスクトップ20案、375px確認枠での最大文字サイズ、動き・キャラクターの切替を確認しています。全ブラウザー・スマートフォン実機・プリンターの機種別確認済みを意味するものではありません。
